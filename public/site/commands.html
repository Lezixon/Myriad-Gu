One catalogue. Clear boundaries.

Use /help inside Discord for the live catalogue. The directory below explains where each system belongs and who normally controls it.

HOW TO READ THIS

PUBLIC members may use the action where appropriate.

STAFF permissions are checked before changes are made.

PRIVATE results are delivered only to the requester.

Normal-message actions such as react hug @member, !rank and !rewards do not add extra slash roots.
