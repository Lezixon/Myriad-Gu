PUBLIC CARD CUSTOMISATION

Make the presentation yours.

The bot keeps its visual language restrained while allowing each server to choose its own media, colours, pings, roles and operating rules.

ONBOARDING

Welcome and goodbye

/welcome set supports a channel, message, colour, image, thumbnail, footer and timestamp. Direct messages are an explicit choice, never a hidden default.

PROGRESSION

Levels and rank cards

/levels settings controls XP, cooldowns, exclusions, announcements, accent colour, background and optional avatar display. Rank cards never silently attach a member picture.

SCHEDULING

Reminder Pro-style controls

/reminders create and /reminders edit support title, colour, message, image, thumbnail, footer, timestamp, repeat interval, timezone, skip days, expiry, user or role pings and deletion of the previous card.

Manage schedules through /reminders list, pause, resume, duplicate and delete. Rich reminders remain cards in Discord rather than collapsing into plain text.

PUBLISHED CARDS

Events, giveaways and panels

Events, giveaways, tickets, forms and role panels all accept optional media and preserve their controls after publishing.

MEDIA POLICY

Nothing forced

No compulsory photograph, footer, timestamp, direct message, quotation, font or decorative theme is inserted into public messages.

FILE SUPPORT

Images and GIFs

PNG, JPEG, WebP and GIF files up to 10 MB are stored privately and re-attached when needed. If a file cannot be fetched, the bot omits it rather than printing a broken placeholder.

BRIDGES

Expressions remain honest

Linked channels forward attached images, GIFs and stickers. If a custom emoji cannot be delivered, its text is omitted rather than replaced with the bot’s own emoji.
