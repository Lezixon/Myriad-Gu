STATUS AND VERIFICATION

Operational checks without secrets.

This page describes the checks shipped with the public package. Live Discord availability still depends on the host, token and gateway.

Command surfaceVERIFIED

Grouped roots and declared options are checked before deployment.

npm run verify:commands
Runtime packageVERIFIED

Syntax, offline checks and Termux compatibility are validated locally.

npm run verify:termux
Public siteVERIFIED

Static pages are checked for required files and public-surface consistency.

npm run verify:public
Persistent statePRIVATE

Reminders, XP, tickets and configuration remain under the private data/ directory.

npm run backup:verify

WHAT THIS PAGE DOES NOT CLAIM

No invented uptime.

This public page does not expose tokens, guild data, message history or a misleading global uptime counter. A hosted status endpoint can be added later when a real monitoring source exists.
