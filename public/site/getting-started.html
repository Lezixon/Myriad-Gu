GETTING STARTED

Install with deliberate permissions.

Start in a disposable test server, confirm the command surface, then move to a persistent host without exposing your token or saved state.

FOUR STEPS

A calm first launch.

  1. Invite the bot with only the permissions your enabled modules require.
  2. Run /server permissions to inspect readiness.
  3. Configure onboarding, levels, reminders, tickets and automations independently.
  4. Register to a test guild first, then use global registration when satisfied.

TERMUX / NODE

Minimal production sequence

npm install
npm run check
npm run verify:termux
bash termux/start.sh

Keep .env and data/ private. Updates preserve both.

COMMAND REGISTRATION

Test quickly

Use npm run deploy:commands for a test guild. Global registration is slower to propagate and should follow successful testing.

PERSISTENCE

Protect the state

Saved reminders, XP, tickets, relationships and configuration live under data/. Back it up before large changes.
